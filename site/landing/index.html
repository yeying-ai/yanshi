动态工作流：兼具智能体灵活性与 DAG 确定性回放 Dynamic Workflow: Plan Once, Execute as a Parallel Flow

由 DynamicWorkflowAgent 在运行期生成拓扑计划，经白名单校验后编译为标准 yanshi_core::Flow 并行执行——只需一次规划开销，后续全程可回放、可设断点。 DynamicWorkflowAgent authors a bounded execution plan at runtime and compiles it via compile_plan_to_flow into an inspectable, parallel Flow.

  • 消除长链路 ReAct 每步重复消耗上下文 Token 的膨胀问题 Eliminates per-step context bloat on multi-branch tasks
  • 编译前强制验证节点白名单、有向无环拓扑与最大步数上限 Enforces node allowlists, acyclicity, and step budgets before execution
